# Notes for Claude

This is Bijon Guha's portfolio site (Vite + React + TypeScript + Tailwind, deployed to GitHub Pages).

- **Writing or updating a case study:** follow `instruction-write-case-studies.md` in this folder.
- **Writing an article:** use `src/content/articles/_TEMPLATE.md`; the same diagram, image and
  confidentiality guidance from `instruction-write-case-studies.md` applies.
- Site content and project data live in `src/config/bijonConfig.ts`.
- Check changes with `npm run build`; preview with `npm run dev` (http://localhost:8080).
- Don't commit, push or deploy unless asked.
